# Benchmarking Purpose

The purpose of this section is to compare inferencing using PyTorch and inferencing using Modular Max.

Previously, Tensorflow was used but after speaking with a google engineer Tensorflow seems to be an outdated approach to machine learning.

Pytorch is the fix and furthermore testing Modular Max is a great opportunity to create metrics surrounding the project.

Modular was bought by Qualcomm in late July 2026 for $3.9 billion dollars. Surely there are benefits of using Mojo and Max for data prep, model training, and inferencing.
